# 麦麦省钱助手（McSaver）

基于 **麦当劳中国官方 MCP** 开发的 WorkBuddy Skill，帮你用最少的钱吃最合适的麦当劳。

> 本项目为「麦当劳程序员节创意开发大赛（1024 造物挑战）」参赛作品，由参赛者独立开发，非麦当劳官方产品。

## 它能做什么
- 🔍 查附近门店
- 🎟️ 查可领优惠券 / 门店券，告诉你怎么薅
- 💰 算套餐到手价（菜单价 − 可用券）
- 🥗 查餐品营养，给减脂期低卡组合建议
- 📅 查麦麦活动日历，不错过限定

## 安装方法（WorkBuddy）
1. 去 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) 用手机号登录，激活并复制 MCP Token。
2. WorkBuddy 左侧「专家·技能·连接器」→「连接器」→ 右上角「自定义连接器」→「配置 MCP」。
3. 填入 `mcp-config.example.json` 的内容，把 `${MCD_MCP_TOKEN}` 换成你在 open.mcd.cn 申请的 Token，保存并启用。
4. 把本仓库作为 Skill 导入（或将 `SKILL.md` 内容放进你的 Skill 目录）。
5. 对话框直接说需求，例如："附近麦当劳有什么券能领？""我想吃巨无霸套餐，到手多少钱？"

## 使用示例
- 用户：附近有麦当劳吗？
- 助手：调 `query-nearby-stores`，列出 3 家最近门店及距离。
- 用户：减脂期怎么点麦当劳？
- 助手：调 `list-nutrition-foods`，给出低卡高蛋白组合 + "仅供参考"。

## 目标用户
- 想省钱又想吃麦当劳的打工人
- 减脂 / 健身期想控制热量的用户
- 想第一时间知道麦记活动和下单优惠的人

## 合规
- 本 Skill 为只读参谋，不调用任何下单 / 支付工具。
- 价格、券、营养以麦当劳官方实时数据为准。
- 详见 `CONTEST_DECLARATION.md`。
